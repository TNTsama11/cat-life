# 猫生修仙模拟器 · 设计文档

> 基于 [remake（人生重开模拟器）](https://github.com/VickScarlet/remake) 仿造改编
> 日期：2026-08-18 · 状态：已评审（待进入实现计划）

## 1. 概述

把「人生重开模拟器」改编为**猫生 + 猫猫修仙模拟器**：玩家投胎成一只猫，先过凡猫的一生，再在机缘下「伐骨洗髓」踏入修仙，历经境界突破、渡劫飞升，最终结算评分并重开。

**核心方针（用户指定）**：文案与丰富性是重中之重；机制级修仙；沙雕整活 + 修仙梗为主、融入温馨；界面加入 SVG 美术元素打破原版单调。

**非目标**：不重写引擎/界面基架，复用 remake 的 pnpm monorepo、React Web、xlsx 数据管线与 condition 条件语言，在其上做机制扩展与内容重写。

## 2. 核心机制

### 2.1 两阶段玩法流

**阶段一 · 凡猫**
1. 起名 → 抽天赋（复用原版 10 选 3、可锁定机制）→ 分配 20 点「猫五维」。
2. 天赋池含「灵根类天赋」（如 灵猫血脉 / 九命玄猫 / 仙缘一线 / 天生道体 / 吞月灵猫，紫/橙稀有度），抽中即保证在猫龄 3~6 岁间触发「伐骨洗髓」。
3. 未抽中灵根者，凡猫阶段每年仍有小概率「机缘事件」（老猫渡劫 / 仙人抚顶 / 误食灵果 …）→ 同样可触发伐骨洗髓。**天赋路径 + 随机机缘路径双通道入道**。
4. 凡猫寿元约 15~25 岁，一生触发抓老鼠、猫条、绝育、流浪、猫咖、招财、成精前兆等事件。

**阶段二 · 修仙**
5. 「伐骨洗髓」触发：专属交互事件 → 暂停游戏 → 弹出洗点界面一次性重选「仙侠五维」→ 获得灵根、踏入炼气、寿元暴涨 → 进入修仙纪元。
6. 修仙一生：修炼、突破、渡劫、斩妖、寻宝、闭关、门派、道侣、秘境，可延续数百至上千年。
7. 终局（飞升 / 留凡当猫妖老祖 / 陨落转世）→ 总结评分 → 重开（天赋锁定、成就继承沿用原版）。

### 2.2 属性系统

| 层 | 属性 | 说明 |
|---|---|---|
| 凡猫五维（出生分配） | 颜值 / 灵性 / 体魄 / 出身 / 快乐 | 可爱值、机灵、体质、主人家条件、心情 |
| 仙侠五维（洗髓重选） | 根骨 / 悟性 / 体魄 / 机缘 / 灵韵 | 修炼资质、悟功法速度、扛雷肉身、遇宝遇劫概率、法力亲和 |
| 成长维度（游戏内） | 修为 · 境界 · 寿元 · 灵气 · 猫龄 | 修为攒满突破；境界提升加寿元；灵气影响修炼速度 |

- 凡猫阶段分配点数只影响「猫五维」；洗髓后「仙侠五维」由玩家一次性重选（同为 20 点、复用分配逻辑），并决定后续修仙成败。
- 原版 CHR/INT/STR/MNY/SPR 槽位被「猫五维」语义复用；「仙侠五维 + 修为/境界/寿元/灵气」为引擎新增状态。

### 2.3 境界与渡劫规则

- **境界七阶**：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → **飞升**。
- 修炼积累「修为」，修为满 → 触发「突破」事件；成功率由 **根骨 + 悟性** 决定。
- **金丹及以上**突破需渡劫：劫雷事件，**体魄 / 法宝 / 灵宠** 加权影响成败；失败轻则修为大减、折寿，重则**陨落**（转世重开）。
- **飞升**为终局大圆满，给出最高评价；也可「留在凡间当猫妖老祖」走另一条圆满线。

## 3. 内容体系

### 3.1 天赋（三类，复用原版互斥/盲盒/专属机制）

| 类别 | 数量目标 | 示例 |
|---|---|---|
| 凡猫天赋 | ~60 | 橘猫基因、拆家能手、招财猫、猫中社牛、纸箱之主 |
| 灵根类天赋 | ~12 | 九命玄猫、灵猫血脉、仙缘一线、天生道体、吞月灵猫 |
| 修仙天赋 | ~60 | 剑心通明、雷灵根、御鼠诀大成、双修伴侣、丹鼎大师 |

- 灵根类天赋抽中即保证触发伐骨洗髓；修仙天赋在洗髓后新开天赋池。

### 3.2 事件（四类 + 特殊事件）

- **凡猫事件（~250）**：按猫龄 0~25 分池。
- **修仙事件（~350）**：按境界分池（闭关、寻宝、斩妖、炼丹、门派、道侣、秘境）。
- **突破事件**：每阶修为满触发，成败各有文案。
- **渡劫事件（金丹起）**：劫雷判定，成功 / 重伤 / 陨落三分支文案。
- **飞升事件**：终局大圆满 + 分支「留凡当猫妖老祖」。

### 3.3 特殊交互事件：伐骨洗髓

原版事件只有「文字 + 效果」。伐骨洗髓需要**中段交互**：触发后暂停游戏、弹出洗点界面重选仙侠五维，再继续。需给引擎新增「交互式事件」类型。

### 3.4 成就（~80，含隐藏）

凡猫成就（寿终正寝的猫、拆迁办主任）、修仙成就（金丹大道、渡过九重雷劫）、飞升成就、隐藏成就（被绝育前成功飞升、九命玄猫真的死九次）。

## 4. 文案规范

- **总量目标**：天赋 ~130 / 事件 ~600+ / 成就 ~80，全部原创猫 + 修仙题材。
- **质量红线**：普通事件 30~80 字；渡劫/突破/飞升/伐骨洗髓写多分支长文案（100~200 字）。
- **基调**：沙雕整活 + 修仙梗（网文黑话、猫奴梗、弹幕式吐槽），关键节点融入温馨（猫与主人/同伴的羁绊）。
- **格式复用**：沿用原版「变量」格式化（猫名、主人名等），让文案量身定制。

## 5. 技术实现

### 5.1 引擎改动（packages/core）

- GameState 新增：realm（境界）、cultivation（修为）、spiritEnergy（灵气）、immortalFive（仙侠五维）、phase（凡猫/修仙）、transformed（是否已洗髓）。
- 中段洗点：新增「交互式事件」，触发伐骨洗髓时引擎暂停、产出待洗点状态，前端弹洗点界面写回后继续。
- 突破/渡劫/飞升判定：修为满触发突破（根骨+悟性算成功率）；金丹起渡劫（体魄/法宝/灵宠加权）；飞升终局。
- 条件语言扩展：新增 REALM / PHASE / CULT / IML 等可判定键，事件/成就条件可用 PHASE=仙、REALM>=金丹。
- 保持原版 start/next/summary/end 生命周期不变，向前兼容凡猫线。

### 5.2 数据管线（packages/data）

- 沿用 xlsx 源文件 + .types.ts 转换器，build:data 生成 TS。
- 改写：talent/event/age/achievement.xlsx，替换为猫 + 修仙内容；age.xlsx 为凡猫猫龄（0~25）与修仙境界各自维护事件权重。

### 5.3 界面改动（apps/web）

- 属性面板：凡猫阶段显示猫五维；洗髓后切换显示「仙侠五维 + 修为 + 境界 + 寿元」。
- 新增洗点界面：伐骨洗髓触发的仙侠五维分配页（改造原版 Alloc 组件）。
- 境界/修为 HUD：Play 页顶部加境界徽章与修为进度条。
- 文案展示：沿用 Message/事件卡片，长文案可滚动，渡劫/飞升有专属高亮样式。

### 5.4 SVG 美术元素（新增）

- 复用原版 TextSvg 思路，新增一套**内联 SVG 组件库**，全部用 currentColor + CSS 变量着色，自动适配 light/dark 主题与四档稀有度（grade-0~3）。
- 素材方向：猫咪形象（家猫/灵猫/九命玄猫剪影、猫爪、猫耳、猫尾、鱼干/猫条/毛线球）、仙侠纹样（祥云、灵剑、丹鼎、符箓、法阵、劫雷、莲花座、飞升祥光）。
- 落点：主页 Logo 与背景纹样；境界徽章（七阶各配专属 SVG 图标）；天赋/成就/事件卡片角标与稀有度饰边；渡劫/飞升/伐骨洗髓的专属过场插画；Play 页顶部 HUD 的灵气/修为进度装饰。
- 原则：SVG 为纯装饰、不阻塞渲染、体积小；配 CSS 动效（祥云漂移、劫雷闪烁、飞升流光）增强氛围。

### 5.5 交付与验证

- 沿用 pnpm monorepo：pnpm build:data && pnpm dev 本地跑通；pnpm build:web 可构建部署。
- 用 core 现有测试骨架为突破/渡劫/洗髓补单测；数据加载与条件判定做完整性自检。
